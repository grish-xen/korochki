- `manage.py check`: 0 проблем.
- `manage.py test portal` с временной SQLite: 8 тестов успешно.

- `npm run build`: успешно.
- `html-validate frontend/dist/index.html`: успешно.
- `css-tree`: синтаксис и значения объявлений CSS распознаны.
